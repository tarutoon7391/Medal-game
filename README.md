# 🎰 Medal Game – ランディングページ

コインをジャラジャラ投げ込む、爽快物理シミュレーションのメダルゲームです。  
このリポジトリはゲーム紹介のランディングページとして構築されています。

---

## 🌐 サイト概要

ブラウザだけで遊べる無料のメダルゲーム紹介ページです。  
GitHub Pages で公開されており、インストール不要でそのまま閲覧・プレイできます。

**ページ構成**

| セクション | 内容 |
|---|---|
| ヒーロー | タイトル・キャッチコピー・CTAボタン |
| ゲーム特徴 | 4つの特徴カード |
| 遊び方 | 4ステップで説明 |
| ギャラリー | スクリーンショット（プレースホルダー） |
| フッター | リンク集 |

---

## 🛠 技術スタック

- **HTML5** – セマンティックなマークアップ
- **CSS3** – CSSカスタムプロパティ・アニメーション・Grid/Flexbox
- **Vanilla JS** – フレームワーク不使用
- **Google Fonts** – Fredoka One / Boogaloo / Nunito / M PLUS Rounded 1c / Noto Sans JP

---

## 🎨 デザイン方針

- カラフル・ポップ・にぎやかな「playful/toy-like」デザイン
- CSSカスタムプロパティで色を一元管理
- グラデーション・グロー・メッシュ背景で奥行きを演出
- ページロード時のスタッガードリビール + スクロールトリガーアニメ
- ジェネリックフォント（Inter/Arial/Roboto）不使用

---

# ローカルで確認（任意のHTTPサーバーで）
